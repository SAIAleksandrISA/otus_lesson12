# MapReduce Расчет Цен

Простая реализация на C++ для вычисления среднего и дисперсии цен из датасета.

## Компоненты

*   **Исходные файлы:**
    *   `mapper.cpp`: Парсит строки CSV, выводит `1\tprice`.
    *   `reducer_mean.cpp`: Вычисляет среднюю цену.
    *   `reducer_variance.cpp`: Вычисляет дисперсию цены.
    *   `test.cpp`: Содержит юнит-тесты.
*   **Сборка:**
    *   `Makefile`: Компилирует исходные файлы в `bin/`.
    *   `Makefile.test`: Компилирует юнит-тесты в `bin/test`.
*   **Скрипт запуска:**
    *   `run_locally.sh`: Оркестрирует выполнение MapReduce.
*   **Настройка CI/CD:**
    *   `.github/workflows/main.yml`: Автоматизирует сборку, запуск и тестирование в GitHub Actions.

## Тестирование

*   Юнит-тесты находятся в `test.cpp`.
*   Для запуска тестов: `make -f Makefile.test`
*   Тесты проверяют функциональность классов `CsvParser` и `Reducer`.
